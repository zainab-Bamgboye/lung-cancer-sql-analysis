# 🫁 Lung Cancer Patient Analysis Using SQL

## 📌 Project Overview

This project analyzes lung cancer patient data using SQL to explore patient demographics, smoking status, cancer stages, survival outcomes, and data quality.

The project demonstrates how SQL can be used to clean, analyze, and extract meaningful insights from healthcare data.

## 🎯 Project Objectives

The analysis aims to:

- Understand the demographic characteristics of the patients
- Examine the distribution of cancer stages
- Analyze smoking status among patients
- Explore survival outcomes
- Identify potential data quality issues
- Generate insights that could support healthcare decision-making

## 🗂️ Dataset

The dataset contains patient-level lung cancer information, including demographic, clinical, and outcome-related variables.

The analysis was performed using Microsoft SQL Server.

## 🛠️ Tools & Technologies

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## 🔎 Analysis Performed

The project includes analysis of:

- Total number of patients
- Average patient age
- Gender distribution
- Age groups
- Cancer stage distribution
- Smoking status
- Survival outcomes
- Survival by gender
- Survival by cancer stage
- Data quality and validation checks

## 💻 SQL Skills Demonstrated

- SELECT
- WHERE
- COUNT()
- AVG()
- GROUP BY
- HAVING
- CASE statements
- AND / OR operators
- NULL handling
- Data validation
- Aggregate functions

## 📊 Key Findings

Some initial findings from the analysis include:

- Average patient age: approximately 55 years
- Female patients: 444,866
- Male patients: 445,134
- Stage I: 222,516 patients
- Stage II: 222,363 patients
- Stage III: 222,594 patients
- Stage IV: 222,527 patients
- Survived patients: 196,004
